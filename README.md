## Getting Started

### For the ML / notebook work

Open the notebook in `CSC_ML/` using Jupyter Notebook or JupyterLab.

```bash
jupyter notebook
```

Then navigate to the relevant notebook file.

### For the RDI platform

Follow the specific setup guides in the sub-project READMEs:

1. Start with the backend:

```bash
cd rdi-platform/backend
pip install -r requirements.txt
```

2. Start the frontend:

```bash
cd rdi-platform/frontend
npm install
npm run dev
```

For a complete setup, including environment variables and database configuration, refer to the backend and frontend documentation inside those folders.
